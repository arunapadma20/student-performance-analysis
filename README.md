Student Performance Analysis
This project analyzes student exam scores using Python and visualizes insights such as average scores, correlations, and effects of gender or test preparation courses.
Dataset: StudentsPerformance.csv
Contains students' scores in Math, Reading, Writing, along with gender and test preparation course info.
- Calculates average score for each student
- Plots distribution of average scores
- Shows correlation heatmap of numeric columns
- Compares average scores by gender
- Shows impact of test preparation course on scores
1. Clone the repository:
   git clone <repo-url>
2. Install dependencies:
   pip install pandas seaborn matplotlib
3. Run the script:
   python students_analysis.py
